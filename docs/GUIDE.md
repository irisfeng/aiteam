# AITeam 使用手册

> 5 分钟上手：你 + 一组 AI 同事，在频道里讨论、在看板上干活、在文档库交付。

---

## 第 0 步：启动

```bash
git clone <repo> && cd aiteam
npm install
npm run build && npm start        # 生产模式，打开 http://localhost:8787
# 或开发模式：npm run dev          # 打开 http://localhost:5173（热更新）
```

不配置任何 key 也能跑（Mock 模式，全流程可点但回复是演示内容）。

## 第 1 步：接入模型（二选一，推荐 B 起步）

**A. Anthropic 官方**：启动前 `export ANTHROPIC_API_KEY=sk-ant-...`。
独享能力：服务端联网调研（web_search）、验收/汇总自动切最强模型。

**B. 第三方（如 DeepSeek）**：界面左下角 **⚙ → 模型供应商**：

| 字段 | 填写 |
|---|---|
| 名称 | DeepSeek |
| Base URL | `https://api.deepseek.com/anthropic` |
| API Key | `sk-…` |
| 默认模型 | `deepseek-v4-pro`（分析/创作） |
| 轻量模型 | `deepseek-v4-flash`（重复执行，自动降本） |

保存后 Mock 徽标消失，内置同事全员可用。已配置的供应商可随时点「编辑」修改。
  联网说明：DeepSeek 官方确认其端点原生支持 Claude 的 Web Search——勾选"支持服务端联网工具"
  即可；系统会自动适配它支持的工具组合（不认 web_fetch 时降级仅搜索，逐级适配，留痕可查），
  搜索结果的总结会产生额外 token 费用（DeepSeek 计费规则）。

## 第 2 步：认识你的团队

- 侧栏「AI 队友」：内置 4 位（产品经理/工程师/代码评审/SEO 优化师）。
- 悬浮某位同事点 **ⓘ** 看档案：人设、模型通道、**长期记忆**（它学到了什么，可清空）。
- 「👥 团队」页：实时忙闲、当前任务、队列、今日交付与用量。

## 第 3 步：四种用法（由浅入深）

### 用法一：聊（问答/讨论）
频道里直接发消息（频道首位 AI 应答），或 `@某同事` 精确指定（可多个）。
AI 之间也会互相 `@` 接力讨论（链深限制防雪崩）。悬浮消息点 **↩** 可引用回复。

### 用法二：派活（单任务自动执行）
「✅ 任务」页新建任务 → 指派给某位同事 → 它自动开工：
联网调研（若可用）→ 写交付物（报告/PPT/数据表）→ **机器验收**（校验者按验收标准逐条核验，
不达标自动退回返工）→ 转「待评审」。**把任务拖进「完成」只能由你来做（关单 human-only）。**

### 用法三：立项（多人协作项目）
在频道里对产品经理说目标，例如：

> @产品经理 立项（先给我看计划）：调研三款开源 ASR 模型并输出选型报告 + 汇报 PPT + 对比数据表。
> 你来拆解分工、并行推进，最后汇总。

它会拆解为带依赖关系的任务计划。说了"先给我看计划"则计划进 **📥 收件箱** 等你批准；
说"全自主"则直接开工。全部交付后 Lead 自动汇总最终报告。
**执行期间你随时可以在频道里插话纠偏**（会注入工作循环），任务卡上有 ⏹ 停止按钮。

### 用法四：例行化（定时自动）
> @产品经理 以后每天 09:30 在这里发昨日进展与今日计划的站会汇总

「团队」页底部可管理/删除例行任务。

## 第 4 步：看产出

- **📄 文档**：所有正式交付物。slides 分页预览可下载 .md（Marp 一键转 PPT）；
  数据表渲染成表格可下载 .csv（直接进 Excel）。
- 频道右侧 **⫿ 任务面板**：本频道任务与交付物，不切视图盯进度。
- **📊 用量**：每日消耗曲线 + 逐次活动账本（谁、干了什么、用的哪个模型、花了多少 token）。

## 进阶：扩编与赋能

- **扩编**：新建频道时按场景卡一键组队（调研/立项/内容/方案）；或从 12 个**角色模板**
  一键招人（数据分析师/PPT 助手/周报助手/调研员…）；或「✚ 自定义角色」完全自建。
- **技能**（⚙ → 技能）：横切的工作方法（深度调研法/金字塔写作法/交付自查清单/头脑风暴），
  启用后全员遵循；可自定义创建。按需开启，不要全开。
- **MCP 插件**（⚙ → MCP 插件）：接入外部工具生态，所有同事自动获得新工具。见手册末尾推荐。

## 治理开关（环境变量）

| 变量 | 作用 | 默认 |
|---|---|---|
| `AITEAM_DAILY_TOKEN_BUDGET` | 日预算硬切断，超限暂停自动开工 | 不限 |
| `TASK_MAX_REVISIONS` | 验收不过的返工上限（超限转人工） | 1 |
| `AGENT_CHAIN_DEPTH` | AI 互相接力的链深上限 | 2 |
| `AITEAM_STRONG_MODEL` / `AITEAM_LIGHT_MODEL` | 官方通道的强/轻模型 | opus-4-8 / haiku-4-5 |
| `AITEAM_MAX_MCP_TOOLS` | 注入工作循环的 MCP 工具上限 | 40 |

## MCP 推荐：第一块插件装什么

**首推 Tavily 搜索（远程 HTTP，5 分钟接入）** —— 给第三方模型通道（如 DeepSeek）补上
真实联网搜索，这是当前最大的能力缺口：

1. 到 tavily.com 注册拿 API key（有免费额度）；
2. ⚙ → MCP 插件 → 类型选 **远程 HTTP**：
   - 名称：`tavily`
   - URL：`https://mcp.tavily.com/mcp/?tavilyApiKey=tvly-你的key`（以 Tavily 控制台展示的为准）
3. 点「测试」确认返回工具数 → 完成。所有同事获得 `mcp__tavily__*` 搜索/抓取工具。

**零依赖备选：文件系统（本地 stdio）** —— 让同事能读写你指定目录里的文件
（喂材料、产出落盘）：

```
名称：files
类型：本地 stdio
命令：npx
参数：-y @modelcontextprotocol/server-filesystem /你的/工作目录
```

> 提示：若 npx 启动超时，先全局安装再用二进制名作命令
> （`npm i -g @modelcontextprotocol/server-filesystem`，命令填 `mcp-server-filesystem`）。
> 安全须知：MCP 工具的能力 = 你授予的范围；文件系统只挂必要目录，带写权限的 server 谨慎接入。
