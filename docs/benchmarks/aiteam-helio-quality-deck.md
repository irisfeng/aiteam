# 自动化从“定时调用”升级为可恢复交付

每个项目都必须有负责人、依赖、验收人和人类关单。

- 卡住时进入待输入，而不是静默失败
- 复核退回后只重跑必要环节
- 任务、裁决、成本与证据统一留痕

```arch
type: flow
目标 | 简报与验收
目标 -> 分工 | 角色路由
分工 -> 双审 | 文字与视觉
双审 -> 关单 | 人类确认
```

> 来源：AITeam 本次实现；BISHENG 工作流架构

<!-- note: 右侧流程是产品必须真实执行的状态链，不是展示性流程图。任何缺依赖、缺裁决或待审批状态都不能直接关单。 -->

# PPT 先过机器下限，再过真实视觉终审

机器门禁负责可证明的问题；视觉模型和人类负责审美判断。

- 字符损坏、无标题、过密、悬空连线直接拦截
- 视觉页、讲者备注、可见来源必须达到覆盖线
- 导出 PPTX、PDF 与逐页截图后再判 PASS

```arch
type: flow
内容 | 结构化稿
内容 -> 渲染 | PPTX与PDF
渲染 -> 初检 | 逐页截图
初检 -> 终审 | PASS或REVISE
```

> 来源：AITeam pptx.ts；回归项 PPTX8 / PPTX9

<!-- note: 机器报告明确不冒充审美评分。即使结构门禁通过，只要截图出现对齐、层级、图文语义或风格问题，视觉终审仍应退回。 -->
